# 🛍️ E-Commerce Project

A full-stack e-commerce web application developed to provide users with a simple and user-friendly online shopping experience.

## 📌 Project Overview

This project is an e-commerce application that allows users to browse products, view product details, add products to the cart, and manage their shopping experience through a web interface.

The project is divided into two main parts:

- **Frontend** – User interface and client-side functionality
- **Backend** – Server-side APIs and application logic

## ✨ Features

- 🏠 User-friendly home page
- 🛍️ Product browsing
- 🔍 Product details
- 🛒 Add to Cart functionality
- 📦 Cart management
- 👤 User registration and login
- 💳 Checkout functionality
- 📱 Responsive user interface
- 🔐 Backend API integration
